# Backend integration status

Current implementation is `backend.ts` with `bridge.ts`. A historical real-model proof used a retired Python backend and does not verify this TypeScript implementation. No current real-model integration or live deployment is established. Bridge unit tests use a mock upstream; composer tests use mocked fetch. The workstation service currently serves the separate project-workspaces build, not this chat backend.

Frontend: exact API in CONTRACT.md. Call bootstrap (credentials include), enroll project once via POST /api/chat/projects, then history/conversation. Origin browser sends automatically for POST; GET needs same-origin Fetch Metadata (normal browser fetch). CSRF header for POST. Origin header can be explicitly set only in test client. Project conversation independent of document. Stop is POST /api/chat/stop; interrupted state requires explicit POST /api/chat/recover before next send. Unknown project history returns 403 until enroll.

Parent launch remains pending: `createBackendService` is a TypeScript service factory without a production entrypoint or static-asset host. Its options require a private state directory and exact public origin; upstream root URL and credential remain server-owned. Production authentication requires an exact trusted Tailscale login and verified Serve-to-loopback provenance. Never expose the listener directly or allow a different proxy to forward attacker-supplied identity headers. Local bootstrap is permitted only for a loopback origin. Startup, effective runtime tool isolation, native cancellation/recovery and real authenticated replies must be verified before promotion.

P2 remains incomplete: the context string is bounded/frozen and untrusted, but live browser MCP lease/query integration and assistant-to-modeling proposals are absent. An empty advertised capability list is not runtime tool isolation. The current backend's isolation callback checks upstream/credential presence only and must not be used as evidence of a deny-all fence. Fix that enforcement and the audited bridge routing, project-session history, cancellation and recovery defects before enabling the transport.
