# Simple Part controls — local operator guide

On a new browser-local project route, create an empty Part. In its center command bar choose Sketch → XY plane → New Sketch. Use Rectangle (width 80, height 50 mm), then Dimension if needed, Finish Sketch, Features → Extrude (distance 6 mm), Preview features, and separately Commit feature revision. The right-side named-feature source is an advanced path, not required for this sequence. The preview is a review mesh, not an exact B-rep or a committed revision.

For a through-hole pattern, add Hole (x 15, y 15, diameter 5 mm) and Linear Pattern (count 3, spacingX 20, spacingY 0), then preview and commit separately. Inspect → Measure picks two visible review-mesh points; Clear removes the measurement. Reload the Part route to read the retained source, mesh and revision history. Line points can close a counterclockwise polygon for extrusion; a separate rectangular radial-axial profile can be fully revolved about Z. Separate rectangular extrusions support outer vertical-corner Fillet or Chamfer.

Limits: one XY profile and one body; extrusion along +Z; full 360° Z revolve only (not circular profiles); through holes on extruded rectangles/circles, not polygons or revolved bodies; 2–16 pattern instances including the source hole; fillet/chamfer on four outer vertical corners of a rectangular plate, terminal in the feature sequence. Invalid source or geometry is rejected, not promoted. Sketch drafts are transient; a preview is not a commit. All outputs remain `needs_human_review`, `fabrication_release=false`, `machine_actuation=false`.

Dirty drafts remain bound to the revision where editing began. If another operation advances the Part, preview and commit stop until an explicit Reload latest revision; the local draft is preserved until that choice. Historical views show their own mesh while keeping the current draft and preview separate. Fillet wall admission reserves the inward error of the actual faceted perimeter rather than trusting analytic arcs alone.

Local verification observed in this worktree: `pnpm run test` — 277 client tests and 19 server tests passed; `pnpm run typecheck` and `pnpm run build` — exit 0; `pnpm run test:e2e` — 32 passed; `pnpm run test:production` — 12 passed against the built production bundle. The browser tests include controls-only Part creation, patterns, finishing, measurement, immutable reload, pending-preview history and external-revision conflict. These are technical checks, not human design approval, GitHub CI, publication, workstation deployment or fabrication release.
