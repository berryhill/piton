# Piton MVI architecture boundary

## Current authority

- Authored intent: immutable source-native Python revision.
- Exact realization: pinned build123d/OCP worker result scoped to revision and environment.
- Review representation: revision/build-scoped GLB plus artifact-local selection map.
- Exchange: STEP derived from a successful exact realization.
- Optional additive derivatives: 3MF/STL, always labeled derivative and unreleased.
- Human state: request changes or accept for MVI review.
- Fabrication release: not implemented in Stage 1.

## Stage 1 non-goals

No assemblies, mechanisms, broad mate solver, generic topology persistence, arbitrary imported code, multi-user synchronization, remote workers, production signatures, fabrication release, slicer actuation, or machine actuation.
